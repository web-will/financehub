# FinanceHub

> Uma aplicação para gerenciamento e organização das finanças pessoais.

## 📋 Sobre o projeto

O **FinanceHub** é uma aplicação desenvolvida para auxiliar no controle financeiro pessoal, permitindo que os usuários acompanhem suas receitas, despesas e movimentações financeiras de forma simples e organizada.

O projeto foi desenvolvido com o objetivo de aplicar conhecimentos de desenvolvimento de sistemas, criação de interfaces e organização de informações financeiras.

## 🚀 Funcionalidades

- Cadastro de receitas.
- Cadastro de despesas.
- Visualização do saldo financeiro.
- Acompanhamento das movimentações financeiras.
- Organização das transações.
- Armazenamento de dados no LocalStorage.
- Persistência dos dados no navegador.
- Interface intuitiva para gerenciamento financeiro.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📦 Como executar o projeto

- Para executar o FinanceHub, você precisa apenas de um navegador web moderno.

- Instalação:
    1 - Clone o Repositório: git clone https://github.com/SEU-USUARIO/financehub.git
    2 - Acesse a pasta do projeto: cd financehub
    3 - Abra o arquivo index.html no navegador. (Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o projeto localmente.)

- OBS: 
    Os dados ficam armazenados localmente no navegador.
    As informações não são enviadas para um servidor.
    Os dados podem ser perdidos caso o armazenamento do navegador seja apagado.
    O armazenamento não é compartilhado automaticamente entre diferentes navegadores ou dispositivos.
